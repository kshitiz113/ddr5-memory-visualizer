🔁 VERILOG → UI INTEGRATION OPTIONS
1. WebAssembly Approach (Browser Execution)
Compile Verilog to C++ via Verilator

Convert to WASM using Emscripten

Load and run simulation inside browser

Ideal for web deployment (Vercel compatible)

2. Local API Server (More Powerful)
Next.js frontend sends simulation data to:

Node.js server with child_process that runs iverilog

Capture output (timing log, data burst info)

Send back to Next.js frontend for visualization

Good for heavy logic and accuracy
